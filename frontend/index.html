TOOLS

两项基础能力

01 / DISCOVER

listKnowledges

列出当前账号可用的知识库及可检索状态。

输入
可选 limit、cursor
输出
知识库列表、下一页游标
02 / RETRIEVE

retrieve

在所选知识库中查找相关片段，返回文件与位置来源。只返回检索结果，不生成回答。

输入
必填 query（1–500 字）、knowledgeIds（1–20 个不重复 ID）；可选 topK（默认 5，1–20）
输出
命中片段、知识库/文件来源、状态
